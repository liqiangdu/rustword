# Changelog

## 0.3.0

- Added page-based layout using the document's page size and margins.
- Added single-page and multi-page views.
- Added 40%–200% document zoom and a fit-to-window action.
- Added page and section break handling and generated page numbers.
- Added Ctrl+1 / Ctrl+2 view shortcuts and Ctrl++ / Ctrl+- / Ctrl+0 zoom shortcuts.

## 0.2.1

- Fixed multi-paragraph table cell layout.
- Added WebP image decoding for charts stored under `.png` part names.
- Added table width, row height, cell margin and vertical-alignment rendering.
- Improved real-world report fidelity and round-trip verification.

## 0.2.0

- Added editable tables, table insertion and row/column controls.
- Added inline image rendering, insertion, resizing and removal.
- Added OOXML media relationship and content-type writing.

## 0.1.0

- Initial minimal Word editor.
- DOCX/DOCM editing with conservative XML round-tripping.
- Legacy `.doc` text import.
- Paragraph styles, formatting, save/save-as and unsaved-change prompts.
